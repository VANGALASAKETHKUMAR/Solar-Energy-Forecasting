# Dataset

The notebook uses the following four CSV files:

- `Plant_1_Generation_Data.csv`
- `Plant_1_Weather_Sensor_Data.csv`
- `Plant_2_Generation_Data.csv`
- `Plant_2_Weather_Sensor_Data.csv`

Download them from the original Kaggle dataset:

https://www.kaggle.com/datasets/anikannal/solar-power-generation-data

After downloading, place all four CSV files in this folder.

The CSV files are intentionally not included in this GitHub repository. Refer to the original dataset page for its data rights and attribution information.
